How it works

Step 1

Kids do chores

Each kid taps "I did it!" on their own phone or the family tablet. Submission goes into your approval queue.

Step 2

Parents approve

You get a push notification. Approve or reject in one tap. Coins credit or screen time unlocks instantly on every family device.

Step 3

Kids redeem

Coins turn into extra screen time, cash, or reward items you've set up. Every transaction is a signed row in an append-only ledger — the receipts are always there.

Install in one command

Works on any Mac (Intel or Apple Silicon), any Linux server, and every Raspberry Pi from Zero 2W through Pi 5.

The easy way

Autodetects OS + CPU, verifies SHA-256, installs as a service that starts on boot. 

curl -fsSL https://raw.githubusercontent.com/danielhemp/chore-coin/main/install.sh | sh

Uses sudo to install into /usr/local/bin and register the service.

The manual way

Grab a binary from the latest release and run it. 

chmod +x chorecoin-*
./chorecoin-* serve \
    --http=0.0.0.0:8090 \
    --dir=/path/to/data

Then open http://localhost:8090 to start the setup wizard.

Docker Compose available too

Prefer containers? The repo ships a three-container docker-compose.yml that's been battle-tested on the family instance for months. Same features, same data model, different distribution.

Common questions

Do I need to know Docker?

No. The one-line install script drops a single binary onto your Mac, Linux server, or Raspberry Pi. It registers itself as a service that starts at boot. Docker Compose is also supported for people who prefer it, but it's optional.

What hardware do I need?

Very little. A Raspberry Pi Zero 2W ($15) is plenty for a family of any size — Chore Coin idles around 30MB of RAM. Any Mac mini, spare Linux laptop, or NAS with Docker also works.

Can my family reach it when I'm not home?

Two options. Free: point a Cloudflare Tunnel at your instance and open port 8090 to the world without touching your router. Paid: pay $12/year for a yourname.chorecoin.family subdomain that DNS-forwards to your instance — no tunnel management required.

Where does my family's data live?

On the machine you install to. A single SQLite file. Back it up by copying one file. Move to a different machine by copying that same file. Never leaves your hardware.

Does it work on iOS / Android?

Yes. Chore Coin is a Progressive Web App — open the URL in Safari or Chrome, "Add to Home Screen," and it behaves like a native app. Works in iOS Assistive Access for younger kids, supports native Web Push for notifications on both platforms.

Can I contribute?

Bug reports, feature requests, and PRs are all welcome on GitHub. This is a side project maintained in evenings — response times are days, not minutes.

What if I want to move to a new machine?

Two clicks. On the old machine: Settings → Download family backup. On the new machine: install Chore Coin, and during the setup wizard choose "Restore from backup" instead of "Fresh install." Your kids, chores, coin balances, and full history come across intact. Then release the license on the old machine and enter it on the new one — same button, one paste.

Can I use my license on more than one server?

One license = one active install. If you want a second family (say, grandparents), buy a second license. If you want to upgrade hardware, release the license on the old machine first; the new one activates immediately. Nothing to email us, no support tickets.

How do I know when there's an update?

The app polls a public announcements feed weekly and shows an in-app banner when there's news — new versions, security notices, breaking changes. No spam, no marketing. Everything else you can watch on the GitHub releases page.
