1. Before you start — what you need

Two things:

  1. Your license key. It looks like CHRC-A1B2-C3D4-E5F6-G7H8. It's in the welcome email you got when you bought Chore Coin. If you can't find that email, search your inbox for "Chore Coin license."
  2. A computer at your house that stays on. Any of these works:
    • A spare laptop you don't use anymore (Mac or Linux — Windows isn't supported yet)
    • A Mac mini, iMac, or Mac Pro (any age from the last 10 years)
    • A $15 Raspberry Pi Zero 2W (the size of a pack of gum — perfect for this)
    • A home NAS (Synology, QNAP, Unraid) if you have one
    Any of these will do fine. Chore Coin uses less memory than a single browser tab.
💡

Which one should I pick? If you have a spare laptop, that's the easiest — you already know how to use it. If you don't, the $15 Raspberry Pi Zero 2W is what most families choose. Plug it into a wall outlet, connect it to your Wi-Fi, and forget it exists.

Once you've picked which computer you'll run Chore Coin on, jump to the section that matches it:

  • If it's a Mac → skip to Part 1a.
  • If it's a Raspberry Pi or Linux computer → skip to Part 1b.

2. Part 1a — On a Mac: open Terminal

Terminal is an app that's already installed on every Mac. It looks intimidating but you'll only use it for one command.

To open Terminal:

  1. Press ⌘ + Space on your keyboard. A search box appears in the middle of the screen.
  2. Type the word terminal and press Return.
  3. A window opens with white or black text on a dark background, and a prompt that looks like: 
    yourname@yourmacs-name ~ %
✓

That's it. Terminal is now open. Leave the window there — you'll paste one line into it in a moment.

Skip to Part 2.

3. Part 1b — On a Raspberry Pi or Linux computer

You need to get to a terminal (also called a "command line" or "shell"). There are two ways depending on your setup.

If the computer has a keyboard + monitor plugged in:

Open the "Terminal" app from the applications menu — usually under Accessories or System Tools. On Raspberry Pi OS the icon is a black square in the top-right of the desktop.

If the computer is "headless" (no monitor):

You'll connect from another computer using SSH.

  1. Find the Raspberry Pi's IP address. Easiest: check your Wi-Fi router's admin page for connected devices; it usually shows up as "raspberrypi."
  2. From another Mac or Linux computer, open Terminal and type: 
    ssh pi@[the-ip-address]
    Replace [the-ip-address] with what you found (e.g. ssh pi@192.168.1.42).
  3. Enter the Pi's password when asked (default on fresh Raspberry Pi OS is raspberry).
✓

You should now see a prompt that ends in $ or #. Continue to Part 2.

4. Part 2 — Run the install command

This is the one command you'll paste. It downloads Chore Coin, installs it, and starts it up as a background service that runs even after you close Terminal.

Copy this whole thing:

curl -fsSL https://raw.githubusercontent.com/danielhemp/chore-coin/main/install.sh | \
  CHORECOIN_LICENSE=CHRC-XXXX-XXXX-XXXX-XXXX sh
⚠️

Before you paste: replace CHRC-XXXX-XXXX-XXXX-XXXX with your real license key from the welcome email. Everything else stays the same. Keep the backslash and the newline in place.

To paste and run:

  1. Click the Terminal window to focus it.
  2. Paste the command:
    • On Mac: ⌘ + V
    • On Linux/Pi: Ctrl + Shift + V
  3. Press Return.
  4. You may be asked for your Mac/Linux password (the one you use to log in). Type it and press Return. You won't see any dots or characters appear as you type — that's normal for Terminal.

What you'll see:

Text will scroll by for 20-40 seconds. You'll see messages like:

Chore Coin installer
  ✓ license key accepted
Platform: darwin/arm64 → chorecoin-darwin-arm64
Finding the latest release...
  ✓ Release v0.1.0
Downloading...
  ✓ checksum verified
  ✓ installed /usr/local/bin/chorecoin
  ✓ data directory /Users/you/Library/Application Support/chorecoin
  ✓ license key staged for setup wizard
  ✓ launchd agent loaded
Chore Coin is running.

  Open in your browser:  http://127.0.0.1:8090
✓

You're 90% done. The last line tells you the address to open in your browser. Copy that URL and continue to Part 3.

⚠️

Something error out? Skip to "If something goes wrong" at the bottom. It covers every failure we've seen and how to fix each in under a minute.

5. Part 3 — Finish setup in your browser

Open the address the installer printed (usually http://127.0.0.1:8090) in Safari, Chrome, or Firefox. You'll see a welcome screen with three steps.

Step 1 — License key

Your license key should already be filled in (the installer handed it to the wizard for you). Click Next →.

Step 2 — Admin account

This account is only for the low-level database screen you'll almost never look at. Suggestions:

  • Admin email: anything (e.g. admin@family.local). Doesn't have to be real.
  • Admin password: at least 10 characters. Write this down somewhere safe. You'll need it if you ever want to poke at the database directly, but that's rare.

Step 3 — Your parent account

This is what you'll actually use every day.

  • Your name: your first name (kids will see it).
  • Your email: a real address — you'll log in with this.
  • Password: at least 8 characters.
  • Avatar: pick an emoji.

Click Finish setup. You'll be signed in automatically and dropped on the app's main screen.

🎉

Chore Coin is now installed and running on your home computer. The rest of this guide covers adding your family and putting Chore Coin on everyone's phone.

6. Part 4 — Add your kids

  1. Tap the gear icon (⚙️) in the top right, then Kids.
  2. Tap + Add a kid.
  3. Enter their name and pick an emoji avatar.
  4. Give them a login so they can sign in on their own phone:
    • Username: their first name in lowercase (e.g. alex).
    • PIN: a 4-6 digit number they'll remember (e.g. their birth month + day).
  5. Tap Save.

Repeat for each kid. You can go back and change any of this later.

7. Part 5 — Add your first chores

There are two kinds of chores:

Base chores

The everyday things each kid needs to do to earn their 60 minutes of screen time. Make the list short — 4 or 5 things works well. Examples:

  • Make your bed
  • Brush your teeth
  • Read 20 minutes
  • Feed the dog

To add base chores: Chores → Base → + Add, then pick which kid it's for.

Bonus chores

Extra jobs kids can do for coins. Give each one a coin value and (optionally) a daily cap. Examples:

  • Empty the dishwasher — 3 coins (max 1/day)
  • Take out the trash — 5 coins (max 1/day)
  • Vacuum the living room — 8 coins
  • Wash the car — 15 coins

To add bonus chores: Chores → Bonus → + Add.

Rewards

Optional: set up things kids can spend coins on beyond screen time. Examples:

  • Movie night — 10 coins
  • Pick dinner — 15 coins
  • Stay up 30 minutes late — 12 coins

To add rewards: Rewards → + Add.

💡

Start small. Add 3-4 base chores and 3 bonus chores to begin with. You can always add more once you see what your kids actually engage with.

8. Part 6 — Put Chore Coin on everyone's phone

Chore Coin isn't in the App Store — you install it by adding a shortcut from your browser. It's just as good, and skips App Store approvals and family sharing headaches.

On iPhone / iPad (Safari):

  1. Open Safari and go to your Chore Coin address. On the same Wi-Fi as your home computer, that's http://[your-computer-name].local:8090. If that doesn't work, use the IP address the installer printed.
  2. Sign in as the kid (their username + PIN).
  3. Tap the Share button (the square with an arrow pointing up).
  4. Scroll down and tap Add to Home Screen.
  5. Tap Add.

A Chore Coin icon now sits on the home screen just like any other app.

On Android (Chrome):

  1. Open Chrome and go to your Chore Coin address.
  2. Sign in.
  3. Tap the three-dot menu → Install app (or Add to Home Screen).
💡

For the family kitchen tablet: create a "dashboard" login (Settings → Users → + Add → role: Dashboard). Add it to the home screen, put the tablet on the counter, and everyone can see today's chores + everyone's coin balances at a glance.

9. If something goes wrong

Nine times out of ten it's one of these. Try the fix, then re-run the install command.

no license key provided

What it means: you didn't paste your key into the command, or you pasted a fake one like CHRC-XXXX-XXXX-XXXX-XXXX.

Fix: open your welcome email, copy the real key (the one that starts with CHRC- followed by 16 random letters + numbers), and paste it in place of CHRC-XXXX-XXXX-XXXX-XXXX.

license key doesn't match the expected format

What it means: the key got mangled during copy-paste — usually an extra space at the start or end, or a line break in the middle.

Fix: re-copy the key straight from your email. It's always 24 characters total, in the shape CHRC-XXXX-XXXX-XXXX-XXXX. No spaces, no line breaks.

Permission denied (publickey) (only appears if you're SSH'd into a Pi)

What it means: the Pi is refusing your SSH key.

Fix: on the Pi itself (with keyboard + monitor plugged in), enable SSH password auth: sudo raspi-config → Interface Options → SSH → Enable. Then try SSH again with the Pi's password.

curl: command not found

What it means: curl isn't installed. On a Mac this shouldn't happen. On Linux/Pi it can happen on very minimal images.

Fix (Linux/Pi): run sudo apt update && sudo apt install -y curl, then run the install command again.

need root or sudo to install to /usr/local/bin

What it means: the installer needs to write to a system folder and doesn't have permission.

Fix: your Mac/Linux account needs to be an admin. On a Mac: System Settings → Users & Groups — your account should show "Administrator" under your name. If it doesn't, sign in as an admin account and re-run.

Service didn't respond within 20s

What it means: the installer finished but the app didn't start up in time. Usually a port conflict — something else is already using port 8090.

Fix: re-run the install command with a different port: 

curl -fsSL https://raw.githubusercontent.com/danielhemp/chore-coin/main/install.sh | \
  CHORECOIN_LICENSE=your-key-here CHORECOIN_PORT=8091 sh
Then open http://127.0.0.1:8091 instead.

The browser page won't load / says "can't connect to server"

Fix: Wait 30 seconds and try again — the service takes a moment to start on first boot. If it still won't load, check the app is actually running:

  • On Mac: launchctl list | grep chorecoin should show a line.
  • On Linux: systemctl status chorecoin should say "active (running)."

If it doesn't, run tail -f ~/Library/Logs/chorecoin/chorecoin.err (Mac) or journalctl -u chorecoin -n 50 (Linux) and email us what you see.

I can't find my Chore Coin address from my kid's phone

What it means: the phone needs to be on the same Wi-Fi network as the computer running Chore Coin.

Fix: make sure both are on the same Wi-Fi. Then find your home computer's name — on Mac it's in System Settings → General → About → Local hostname (e.g. macbook-air.local). On the phone, open Safari and go to http://[that-name].local:8090.

If that doesn't work, use the IP address instead: on Mac, hold Option and click the Wi-Fi icon in the menu bar — the IP address is shown at the top. Then on the phone go to http://[that-ip]:8090.
