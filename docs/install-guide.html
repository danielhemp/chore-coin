1. Before you start — what you need

Two things:

  1. Your license key. It looks like CHRC-A1B2-C3D4-E5F6-G7H8. It's in the welcome email you got when you bought Chore Coin. If you can't find that email, search your inbox for "Chore Coin license."
  2. A computer at your house that stays on. Any of these works:
    • A spare laptop you don't use anymore (Mac or Linux — Windows isn't supported yet)
    • A Mac mini, iMac, or Mac Pro (any age from the last 10 years)
    • A $15 Raspberry Pi Zero 2W (the size of a pack of gum — perfect for this)
    • A home NAS (Synology, QNAP, Unraid) if you have one
    Any of these will do fine. Chore Coin uses less memory than a single browser tab.
💡

Which one should I pick? If you have a spare laptop, that's the easiest — you already know how to use it. If you don't, the $15 Raspberry Pi Zero 2W is what most families choose. Plug it into a wall outlet, connect it to your Wi-Fi, and forget it exists.

2. Two ways to install: easy vs. classic

There are two ways to get Chore Coin running. Pick whichever feels less scary:

  • Easy path — a launcher file you double-click. Works on Mac, Windows, and Raspberry Pi. You'll see one "downloaded from the internet" security warning the first time (both macOS and Windows do this for anything unsigned) — the guide below walks you through clicking past it in about 5 seconds. After that it's just: download, double-click, done.
  • Classic path — one command in Terminal. No security warning to click past. Slightly more intimidating because you're staring at a text-only prompt. Fine if you've used Terminal before.

Both paths do exactly the same thing under the hood. Both take about the same amount of time. Pick the one you're more comfortable with:

  • Installing on a Mac? → jump to easy path — Mac.
  • Installing on a Windows PC? → jump to easy path — Windows.
  • Installing on a Raspberry Pi or Linux computer? → jump to easy path — Pi.
  • Prefer the classic Terminal command? → jump to classic path.

3. Easy path — Mac (double-click launcher)

You'll download one small file, double-click it, and answer one prompt. Total time: under a minute.

Step 1 — Download the launcher

Click this link on your Mac: install-chorecoin-mac.command

Safari will download it to your Downloads folder. If Safari asks whether to allow the download, click Allow.

Step 2 — Double-click to run it

Open your Downloads folder and double-click install-chorecoin-mac.command.

🛡️

You'll see this warning the first time:

"install-chorecoin-mac.command" cannot be opened because it is from an unidentified developer.

This is macOS being cautious about any file downloaded from the internet. Chore Coin isn't a Mac App Store app (that would add a $99/year Apple fee to your $20 price), so this warning is expected. Here's how to click past it:

  1. Click Done or OK to close the warning.
  2. Go to System Settings → Privacy & Security.
  3. Scroll down to the security section. You'll see a message: "install-chorecoin-mac.command was blocked to protect your Mac."
  4. Click Open Anyway next to that message.
  5. Confirm with your Mac password or Touch ID.

On older macOS versions (Monterey and earlier) you can instead right-click the file → Open → click Open in the confirmation dialog. Same result, fewer clicks.

You only need to do this once. After allowing it, the file will double-click normally forever.

Step 3 — Follow the on-screen prompts

A Terminal window opens showing:

🪙  Chore Coin — Mac Installer

  This will download and install Chore Coin on your Mac.
  It takes about 30 seconds. You'll see progress as it works.

  Press Return to begin, or close this window to cancel.

Press Return, paste your license key from the welcome email, press Return again, and wait about 30 seconds. Skip to "Finish setup in your browser" when it's done.

4. Easy path — Windows (double-click launcher)

Works on Windows 10 (recent build) and Windows 11. Same idea as Mac — download, double-click, answer prompts.

Step 1 — Download the launcher

Click this link on your Windows PC: install-chorecoin-windows.bat

Edge, Chrome, or Firefox will save it to your Downloads folder. If your browser warns that "this file may harm your computer," click Keep or Keep anyway. It won't — it's just a plain-text script (you can open it in Notepad and read it yourself if you want).

Step 2 — Double-click to run it

Open your Downloads folder and double-click install-chorecoin-windows.bat.

🛡️

You'll see this warning the first time:

"Windows protected your PC. Microsoft Defender SmartScreen prevented an unrecognized app from starting."

This is Windows SmartScreen being cautious about any file downloaded from the internet. Same reason as Mac — we're not paying for an EV code-signing certificate ($300/year) to keep your license price at $20. Here's how to click past it:

  1. Click More info (the small link near the top of the warning).
  2. Click Run anyway (the button that appears at the bottom).

You only need to do this once. After allowing it, the file will double-click normally forever.

Step 3 — Follow the on-screen prompts

A Command Prompt window opens showing the welcome screen. Press any key, paste your license key from the welcome email, press Enter, and wait about 30 seconds. Skip to "Finish setup in your browser" when it's done.

💡

Windows-specific note: Chore Coin will start automatically every time you log in to Windows. If you sign out of Windows or your computer restarts, Chore Coin will start again the next time you log in. If you want Chore Coin to keep running while nobody is logged in, you'll need a slightly different setup — email us and we'll help.

5. Easy path — Raspberry Pi / Linux (double-click launcher)

Works best on Raspberry Pi OS Desktop, Ubuntu, or any Linux with a graphical file manager. If your Pi is headless (no screen), see the classic Terminal path instead — it's faster over SSH anyway.

Step 1 — Download the launcher

Right-click install-chorecoin-pi.sh and choose Save link as…. Save it to your Downloads or Desktop.

Step 2 — Make it executable

Right-click the downloaded file → Properties → Permissions tab → check Allow executing file as program → close.

(On Ubuntu the toggle is named "Execute: Allow executing file as program." Similar wording elsewhere.)

Step 3 — Double-click to run it

Double-click the file. Raspberry Pi OS will ask what to do — pick Execute in Terminal. On other Linux distros it may just run.

💡

If double-clicking opens the script in a text editor instead of running it, right-click and pick Open in Terminal or Run in Terminal from the menu.

Step 4 — Follow the on-screen prompts

A Terminal window opens with the Chore Coin welcome screen. Press Return, paste your license key, press Return again, and wait about 30 seconds. Skip to "Finish setup in your browser".

6. Classic path — Terminal command

Prefer to skip the download-and-double-click and just paste a command? This is the same install, done in one line.

On a Mac:

  1. Press ⌘ + Space, type terminal, press Return.
  2. Paste this line (after replacing the fake key with your real one): 
    curl -fsSL https://raw.githubusercontent.com/danielhemp/chore-coin/main/install.sh | \
  CHORECOIN_LICENSE=CHRC-XXXX-XXXX-XXXX-XXXX sh
  3. Press Return. Enter your Mac password if asked.

On a Raspberry Pi or Linux computer:

  1. Open Terminal (or SSH in). Paste the same command above.
  2. Press Return. Enter your password if asked.

On Windows:

  1. Press ⊞ (Windows key), type powershell, press Enter.
  2. Paste these two lines together (replace the fake key): 
    $env:CHORECOIN_LICENSE = 'CHRC-XXXX-XXXX-XXXX-XXXX'
iwr -UseBasicParsing https://raw.githubusercontent.com/danielhemp/chore-coin/main/install.ps1 | iex
  3. Press Enter.

What you'll see (all platforms):

Text scrolls by for about 30 seconds. You'll see messages like ✓ license key accepted, ✓ checksum verified, ✓ installed, and finally:

Chore Coin is running.

  Open in your browser:  http://127.0.0.1:8090
✓

You're 90% done. Copy that URL and continue to the next section.

⚠️

Something error out? Skip to "If something goes wrong" at the bottom. It covers every failure we've seen and how to fix each in under a minute.

7. Finish setup in your browser

Open the address the installer printed (usually http://127.0.0.1:8090) in Safari, Chrome, or Firefox. You'll see a welcome screen with three steps.

Step 1 — License key

Your license key should already be filled in (the installer handed it to the wizard for you). Click Next →.

Step 2 — Admin account

This account is only for the low-level database screen you'll almost never look at. Suggestions:

  • Admin email: anything (e.g. admin@family.local). Doesn't have to be real.
  • Admin password: at least 10 characters. Write this down somewhere safe. You'll need it if you ever want to poke at the database directly, but that's rare.

Step 3 — Your parent account

This is what you'll actually use every day.

  • Your name: your first name (kids will see it).
  • Your email: a real address — you'll log in with this.
  • Password: at least 8 characters.
  • Avatar: pick an emoji.

Click Finish setup. You'll be signed in automatically and dropped on the app's main screen.

🎉

Chore Coin is now installed and running on your home computer. The rest of this guide covers adding your family and putting Chore Coin on everyone's phone.

8. Add your kids

  1. Tap the gear icon (⚙️) in the top right, then Kids.
  2. Tap + Add a kid.
  3. Enter their name and pick an emoji avatar.
  4. Give them a login so they can sign in on their own phone:
    • Username: their first name in lowercase (e.g. alex).
    • PIN: a 4-6 digit number they'll remember (e.g. their birth month + day).
  5. Tap Save.

Repeat for each kid. You can go back and change any of this later.

9. Add your first chores

There are two kinds of chores:

Base chores

The everyday things each kid needs to do to earn their 60 minutes of screen time. Make the list short — 4 or 5 things works well. Examples:

  • Make your bed
  • Brush your teeth
  • Read 20 minutes
  • Feed the dog

To add base chores: Chores → Base → + Add, then pick which kid it's for.

Bonus chores

Extra jobs kids can do for coins. Give each one a coin value and (optionally) a daily cap. Examples:

  • Empty the dishwasher — 3 coins (max 1/day)
  • Take out the trash — 5 coins (max 1/day)
  • Vacuum the living room — 8 coins
  • Wash the car — 15 coins

To add bonus chores: Chores → Bonus → + Add.

Rewards

Optional: set up things kids can spend coins on beyond screen time. Examples:

  • Movie night — 10 coins
  • Pick dinner — 15 coins
  • Stay up 30 minutes late — 12 coins

To add rewards: Rewards → + Add.

💡

Start small. Add 3-4 base chores and 3 bonus chores to begin with. You can always add more once you see what your kids actually engage with.

10. Put Chore Coin on everyone's phone

Chore Coin isn't in the App Store — you install it by adding a shortcut from your browser. It's just as good, and skips App Store approvals and family sharing headaches.

On iPhone / iPad (Safari):

  1. Open Safari and go to your Chore Coin address. On the same Wi-Fi as your home computer, that's http://[your-computer-name].local:8090. If that doesn't work, use the IP address the installer printed.
  2. Sign in as the kid (their username + PIN).
  3. Tap the Share button (the square with an arrow pointing up).
  4. Scroll down and tap Add to Home Screen.
  5. Tap Add.

A Chore Coin icon now sits on the home screen just like any other app.

On Android (Chrome):

  1. Open Chrome and go to your Chore Coin address.
  2. Sign in.
  3. Tap the three-dot menu → Install app (or Add to Home Screen).
💡

For the family kitchen tablet: in the parent app, go to Settings → Dashboards → Add a dashboard. Give it a name like "Kitchen tablet", pick a username (e.g. kitchen), and set a PIN. Sign the tablet in with those credentials, add it to the home screen, put the tablet on the counter — and everyone can see today's chores + everyone's coin balances at a glance. Dashboard accounts can see everything and submit chores on any kid's behalf, but can't approve, adjust, or manage — so anyone walking up to the kitchen tablet can't accidentally break anything.

11. If something goes wrong

Nine times out of ten it's one of these. Try the fix, then re-run the install command.

no license key provided

What it means: you didn't paste your key into the command, or you pasted a fake one like CHRC-XXXX-XXXX-XXXX-XXXX.

Fix: open your welcome email, copy the real key (the one that starts with CHRC- followed by 16 random letters + numbers), and paste it in place of CHRC-XXXX-XXXX-XXXX-XXXX.

license key doesn't match the expected format

What it means: the key got mangled during copy-paste — usually an extra space at the start or end, or a line break in the middle.

Fix: re-copy the key straight from your email. It's always 24 characters total, in the shape CHRC-XXXX-XXXX-XXXX-XXXX. No spaces, no line breaks.

Permission denied (publickey) (only appears if you're SSH'd into a Pi)

What it means: the Pi is refusing your SSH key.

Fix: on the Pi itself (with keyboard + monitor plugged in), enable SSH password auth: sudo raspi-config → Interface Options → SSH → Enable. Then try SSH again with the Pi's password.

curl: command not found

What it means: curl isn't installed. On a Mac this shouldn't happen. On Linux/Pi it can happen on very minimal images.

Fix (Linux/Pi): run sudo apt update && sudo apt install -y curl, then run the install command again.

need root or sudo to install to /usr/local/bin

What it means: the installer needs to write to a system folder and doesn't have permission.

Fix: your Mac/Linux account needs to be an admin. On a Mac: System Settings → Users & Groups — your account should show "Administrator" under your name. If it doesn't, sign in as an admin account and re-run.

Service didn't respond within 20s

What it means: the installer finished but the app didn't start up in time. Usually a port conflict — something else is already using port 8090.

Fix: re-run the install command with a different port: 

curl -fsSL https://raw.githubusercontent.com/danielhemp/chore-coin/main/install.sh | \
  CHORECOIN_LICENSE=your-key-here CHORECOIN_PORT=8091 sh
Then open http://127.0.0.1:8091 instead.

The browser page won't load / says "can't connect to server"

Fix: Wait 30 seconds and try again — the service takes a moment to start on first boot. If it still won't load, check the app is actually running:

  • On Mac: launchctl list | grep chorecoin should show a line.
  • On Linux: systemctl status chorecoin should say "active (running)."

If it doesn't, run tail -f ~/Library/Logs/chorecoin/chorecoin.err (Mac) or journalctl -u chorecoin -n 50 (Linux) and email us what you see.

I can't find my Chore Coin address from my kid's phone

What it means: the phone needs to be on the same Wi-Fi network as the computer running Chore Coin.

Fix: make sure both are on the same Wi-Fi. Then find your home computer's name — on Mac it's in System Settings → General → About → Local hostname (e.g. macbook-air.local). On the phone, open Safari and go to http://[that-name].local:8090.

If that doesn't work, use the IP address instead: on Mac, hold Option and click the Wi-Fi icon in the menu bar — the IP address is shown at the top. Then on the phone go to http://[that-ip]:8090.
